  1. Navigate to Pay & Transfer menu (paymentMenu)

H. Key Migration Decisions

DecisionRationale
Create ACT payment within TC08 (not depend on TC01 reference) Playwright tests run in parallel with isolated browser contexts. Shared state via variables between test blocks doesn't work. Self-contained tests are mandatory.
Use javaScriptsClick for editButton Matches Protractor jsClick pattern. Standard .click() may fail on Angular components with overlay elements.
Try/catch for continueBtn with 5s timeout The "Continue" dialog appears conditionally (cognitive/compliance check). If not present, test should proceed without failing.
Use enterTextarea for amount (not .fill()) Learnings L-002: .fill() silently fails on ShuRu-based Angular components. enterTextarea includes click-clear-type-blur handling.
30s timeout for status assertion Learnings: ACT view page #act-view-status renders placeholder text for >10s before actual value loads. Default 10s compareUIVsJsonValue timeout is insufficient.
