F. Key Learnings from This Migration

#LearningRule
1No hardcoded locators in webComponents.tsAccept locators as parameters; define them in page classes
2No hardcoded values in spec filesAll values from SG_testData.json; create separate fields for search vs view values
3Autocomplete filter must be uniqueInclude account number + currency in filter (e.g., "03030303 (SGD)"), not just currency
4Angular checkboxes need label-clickUse toggleAngularCheckbox() reusable method with retry loop
5View page values ≠ search textMaintain separate test data fields: fromAccount (search), fromAccountViewValue (assertion)
6Always add delete cleanupClean up "Pending Approval" payments at end of create tests
