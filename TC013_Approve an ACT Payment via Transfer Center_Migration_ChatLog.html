D. Key Learnings — ACT Approve Flow

Approve Section on ACT View Page

  • The ACT view page for "Pending Approval" payments shows an approve section with two buttons: button#push-btn[name="approve"] ("Approve now" — mobile push) and button[name="approve"] ("Approve" — toolbar)
  • Both share name="approve" — use viewPageApproveButton = button[name="approve"]:not(#push-btn) to uniquely target the toolbar button
  • The SMS challenge is NOT auto-sent — must explicitly click getChallengeSMS to request it
  • After entering the challenge response code, the toolbar Approve button becomes enabled (wait with 30s timeout)

ManagePayroll TC012 Pattern — Must Follow Exactly

  • Step 16: scrollToElement(approveSubmitButton) + javaScriptsClick — expand the approve checkbox section
  • Step 17: clickWhenVisibleAndEnabled(pushApprovalOption) — expand the SMS sub-section
  • Step 18: clickWhenVisibleAndEnabled(getChallengeSMS) — request the SMS challenge code
  • Step 19: enterTextarea(challengeResponse, CHALLENGEVIASMSCODE) — enter '12345678'
  • Step 19b: expect(viewPageApproveButton).toBeEnabled({ timeout: 30_000 })
  • Step 20: clickWhenVisibleAndEnabled(viewPageApproveButton) → dismiss dialog

Post-Approval

  • Approved transactions cannot be deleted (Delete button is disabled) — no cleanup step needed
  • Final status depends on bank processing speed — validate against a set of valid statuses rather than a single expected value
