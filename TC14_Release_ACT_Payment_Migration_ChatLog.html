Key Learnings Captured

LearningDetail
Autocomplete dropdown disambiguation When multiple accounts share similar names/currencies, use chained .filter() calls to narrow to a unique match. Single-attribute filters like (SGD) are ambiguous.
Status field loading delay The ACT view page status field (#act-view-status) shows placeholder text for >10 seconds on high-amount payments. Use toContainText with 30s timeout — never accept raw placeholder values as valid.
ApproveNow on preview page pattern Scroll to submit → javaScriptsClick(approvalNowCheckBox) → wait 2s → click pushOption → click getChallengeSMS → enter code → Submit
Release flow (ManagePayroll TC013 pattern) Logout → Login User2 → Approvals → Release tab → search → select + release → submit → verify success → confirm removed → validate in Transfer Center
