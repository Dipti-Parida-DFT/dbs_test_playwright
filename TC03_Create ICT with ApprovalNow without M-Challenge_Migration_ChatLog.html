F4. Learnings Added to learnings.md

  • High-Amount ApprovalNow (ICT — Intra Company Transfer)
    • When payment amount exceeds single-approval limit (e.g., 90,000,001), preview page shows "Approve Now" text link instead of hidden checkbox (input[name="approveNow"])
    • Must use pages.IntraCompanyTransferPage.approveNowLink via webComponents.clickWhenVisibleAndEnabled()
    • After clicking link, challenge response field appears directly (without M-Challenge) — no "Get Challenge via SMS" click needed
    • Final status: "Partial Approved" (not Completed) — multi-level approval required
    • For standard-amount (e.g., 1100), the hidden checkbox pattern still applies
  • Transaction Delete (Cleanup) — Reusable Method
    • ALWAYS use pages.PayrollPage.deleteOpenPayeeOrReferenceNo() for transaction delete
    • Do NOT manually click delete button + dialog + dismiss
    • Works across all payment types (ACT, ICT, TT, CrossBorder, Payroll)
    • Method does NOT dismiss popup — handle if further navigation needed
