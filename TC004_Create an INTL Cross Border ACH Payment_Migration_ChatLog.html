Section F — Key Learnings (TC004)

  1. INTL New Payee form has different input names: Bank ID is swift-selector (NOT bulk-newPayee-bankId), nickname is new-payee-nick-name (with extra hyphen), payee category has no name attribute — use getByPlaceholder('Please select').
  2. Payee nickname is mandatory: The Protractor source did NOT fill this field — it was added to the UI after Protractor tests were written. "Add payee" button stays disabled without it.
  3. Payee category is mandatory for INTL payees: Use click → ArrowDown → Enter to select the first option from the dropdown.
  4. Bank ID search requires keyboard events: fill() does NOT trigger Angular reactive form's search. Use keyboard.type() instead, then wait for .search-result-container to appear and click it.
  5. "Find bank ID" button clears the input: Do NOT click this button after typing — it resets the search field. Auto-search via keyboard.type() is sufficient.
  6. Use page.evaluate() to discover field names: When ARIA snapshots don't show name attributes, dump all inputs via document.querySelectorAll('input') to find actual field names.
  7. Strict mode violations on INTL detail fields: purposePaymentLine, additionalInfoLine, paymentDetailLine resolve to 2 elements when multiple payees exist — always use .first().
  8. "Add payee" button enable guard: Use expect(addPayee).toBeEnabled({ timeout }) before clicking to detect unfilled mandatory fields early, rather than failing later on missing downstream elements.
